BAGBACK PRESENTATION DEMO

Open index.html in a browser to run the demo.

TRY THE LUGGAGE:
1. Open the Finder Portal.
2. Click "Try the live presentation demo" or enter BB-48291.
3. View the sample suitcase and its protected recovery information.
4. Send a sample anonymous recovery message.

For a QR code to open the website directly, host this folder on a public static website host and create a QR code for:
https://YOUR-PUBLIC-SITE/?find=BB-48291

Important:
- This is a classroom prototype, not a production recovery service.
- Sample bag data and messages are simulated in the visitor's browser.
- It does not share messages between different devices.
- Do not enter real personal information.
- Real cross-device recovery requires a secure backend, user authentication, and a hosted database.
